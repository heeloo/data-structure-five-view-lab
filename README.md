# 数据结构五维教学实验室

GitHub Pages 前端 + Render 后端的数据结构可视化实验室。

五个同步视角：PSEUDO / C / STORAGE / POINTER / EXECUTION。

## v1.6 演示

- 单链表头插、尾插、指定位置插入、删除首元结点、迭代反转
- 顺序表指定位置插入（中间插入，需要搬移元素）
- 顺序表尾插法 append（容量充足时无需搬移）
- 顺序表顺序查找、指定位置删除和满容量拒绝写入
- 顺序栈 push / pop
- 循环队列 enqueue / dequeue（含 `rear` 回绕）
- 二叉搜索树递归插入、迭代搜索和双孩子结点删除（含中序后继替换）
- 红黑树连续插入 1、0，以及 LL、RR、LR、RL 四类插入旋转和红黑性质验证
- 图的广度优先搜索 BFS（队列联动）
- 图的深度优先搜索 DFS（递归栈联动）
- 邻接表建图、添加边和删除边（表头数组、Edge 链与图拓扑同步）
- 两个升序单链表原地合并（多链表同屏、逐结点摘接、尾指针推进、剩余段串接和自动不变量检查）
- AVL 树 LL、RR、LR、RL 四类旋转（高度与平衡因子验证）
- 红黑树删除双黑修复（红/黑兄弟、近侄/远侄颜色分支）
- Treap 插入与连续旋转（BST 键序 + priority 堆序）
- 二叉最大堆建堆、插入上浮和删除堆顶下沉
- 开放定址哈希表线性/二次探测、墓碑删除和槽位复用
- 并查集按秩合并与路径压缩
- 线段树区间查询、单点更新与回溯聚合
- Trie 插入、搜索、前缀匹配和终止标记

每个演示都由后端使用 Clang `-O0 -g` 编译，并优先通过 LLDB 源码断点采集真实运行状态。统一 Snapshot Model 同时驱动 ALGORITHM、SOURCE、MEMORY、STRUCTURE、EXECUTION 五个视图。

页面会为每个算法明确显示操作方法、操作位置、存储结构、初始状态、目标结果、时间复杂度、辅助空间、前置条件和关键规则，并支持持久化的明暗主题切换。

树快照协议兼容可选的 `parent`、`color`、`height`、`balance`、`priority` 字段，同一 Renderer 可继续扩展到 AVL、Treap 等平衡树，而不需要重新定义五视图的数据流。
